# Decision records

One file per decision that was argued rather than obvious, numbered in the
order they were taken. A record says what was decided, what it cost, and what
was rejected. It doesn't say what the code does; the code says that better.

A record is not edited once accepted. A later decision supersedes it, in a new
file that says so.
